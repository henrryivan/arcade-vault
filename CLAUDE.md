## Project

Arcade Vault: a platform for playing games online and competing for the highest score. The README says development follows Spec Driven Design (`/spec` and `/spec-impl` skills, installed via `npx skills@latest add Klerith/fernando-skills`). The project is at an early stage: it is still the Create Next App scaffold (`app/page.tsx`, default metadata in `app/layout.tsx`).

## Commands

```bash
npm run dev     # dev server (http://localhost:3000)
npm run build   # production build
npm start       # serve production build
npm run lint    # eslint (flat config, eslint.config.mjs)
```

No test runner is configured.

## Next.js version warning

This uses Next.js 16.4.6 with React 19.3 — newer than typical training data and with breaking changes. Per `AGENTS.md`, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`) before writing Next.js code, and heed deprecation notices. `AGENTS.md` is regenerated by `next dev`.

## Architecture notes

- App Router only (`app/`). Root layout uses the globally typed `LayoutProps<"/">` helper (no import needed) and loads Geist fonts via `next/font/google`.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`. With `cacheComponents`, dynamic/uncached data access has rules that differ from older Next.js — check the docs before fetching data in components.
- Tailwind CSS v4 is wired through Turbopack with a custom `turbopack.rules` loader (`@tailwindcss/turbopack`) in `next.config.ts`, not PostCSS. Styling is `@import "tailwindcss"` plus `@theme inline` tokens in `app/globals.css` (light/dark via `prefers-color-scheme`).
